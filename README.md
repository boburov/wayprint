# 🖨️ Wayprint — Print Xizmati

**Wayprint** — bu O‘zbekiston bo‘ylab futbolka, kurta, kepka va boshqa mahsulotlarga **maxsus rasm, logo yoki dizayn** chop etish xizmati.

![Wayprint preview](https://wayprint.uz/icons/wayprint-logo.png)

---

## 🚀 Texnologiyalar

Bu loyiha quyidagi texnologiyalar asosida qurilgan:

- **Next.js** — Frontend framework
- **Tailwind CSS** — Styling
- **TypeScript** — Barqaror va toza kod
- **Vercel** — Hosting (agar ishlatilgan bo‘lsa)
- **Figma/Canva** — Dizayn preview rasm uchun
